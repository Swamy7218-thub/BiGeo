One REST endpoint. Any address format. Structured JSON response with coordinates, district, mandal, and confidence.

Base URL
https://v34s17v3h2.execute-api.ap-south-1.amazonaws.com/v1
bash 
curl -X POST https://v34s17v3h2.execute-api.ap-south-1.amazonaws.com/v1/parse \
  -H "x-api-key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"address": "Yellareddyguda, Siddipet"}'
python 
import requests

url = "https://v34s17v3h2.execute-api.ap-south-1.amazonaws.com/v1/parse"
headers = {
    "x-api-key": "YOUR_API_KEY",
    "Content-Type": "application/json"
}
payload = {"address": "Yellareddyguda, Siddipet"}

response = requests.post(url, json=payload, headers=headers)
data = response.json()

print(data["lat"], data["lng"])
# 18.1018  78.8520
javascript 
const res = await fetch(
  "https://v34s17v3h2.execute-api.ap-south-1.amazonaws.com/v1/parse",
  {
    method: "POST",
    headers: {
      "x-api-key": "YOUR_API_KEY",
      "Content-Type": "application/json",
    },
    body: JSON.stringify({ address: "Yellareddyguda, Siddipet" }),
  }
);
const { lat, lng, district } = await res.json();
console.log(`${district}: ${lat}, ${lng}`);
// SIDDIPET: 18.1018, 78.8520

How it works

Parse to GPS in three steps

Submit an address in any format. Get precise coordinates and metadata back in under 2 seconds.

1
Send any address
POST a village name, landmark, or rough description in Telugu, Hindi, or English. No special formatting required.
2
AI resolves it
Bedrock KB searches 652K villages semantically. Claude Sonnet 4.6 structures the address. HERE Maps (Amazon Location Service) verifies GPS coordinates.
3
Get GPS + metadata
Receive lat/lng, district, mandal, confidence score, detected language, and model used — all in a single JSON response.
