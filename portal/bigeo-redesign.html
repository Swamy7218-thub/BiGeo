How it works

5 steps. Under 2 seconds.

Every address goes through our AI pipeline — translation, parsing, GPS enrichment, and cross-validation before returning structured JSON.

03

04
📍

05
✅
Return JSON
Structured response with lat/lng, confidence score, and full admin hierarchy.

Quick Start

One endpoint.
Zero setup.

Get your API key, make your first call in 30 seconds.

curl -X POST https://v34s17v3h2.execute-api.ap-south-1.amazonaws.com/v1/parse \ -H "x-api-key: YOUR_API_KEY" \ -H "Content-Type: application/json" \ -d '{"address": "Yellareddyguda, Siddipet"}'
import requests res = requests.post( "https://v34s17v3h2.execute-api.ap-south-1.amazonaws.com/v1/parse", headers={"x-api-key": "YOUR_API_KEY"}, json={"address": "Yellareddyguda, Siddipet"} ) data = res.json() print(data["lat"], data["lng"]) # 18.1021 78.8491
const res = await fetch( "https://v34s17v3h2.execute-api.ap-south-1.amazonaws.com/v1/parse", { method: "POST", headers: { "x-api-key": "YOUR_API_KEY" }, body: JSON.stringify({ address: "Yellareddyguda, Siddipet" }) } ); const { lat, lng, district } = await res.json();
