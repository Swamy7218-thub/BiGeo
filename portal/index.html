API Reference

Two endpoints. Simple integration.

Base URL: https://v34s17v3h2.execute-api.ap-south-1.amazonaws.com/v1

POST /parse Parse a raw address

Accepts an unstructured Indian address string. Returns structured JSON with all geographic components, GPS coordinates, and a confidence score.

FieldTypeNotes
addressstringrequired  Raw address, min 5 chars
# Request curl -X POST https://v34s17v3h2.execute-api.ap-south-1.amazonaws.com/v1/parse \ -H "Content-Type: application/json" \ -H "x-api-key: YOUR_API_KEY" \ -d '{"address": "Near banyan tree, Yellareddyguda, Siddipet"}' # Response { "input_address": "Near banyan tree, Yellareddyguda, Siddipet", "structured_address": "Yellareddyguda, Siddipet Mandal, Siddipet District, Telangana", "village": "Yellareddyguda", "mandal": "Siddipet", "district": "Siddipet", "state": "Telangana", "pincode": "502103", "lat": 18.1018, "lng": 78.8522, "confidence_score": 0.82, "latency_ms": 443, "source": "cache" }
