Architecture

Three layers. One result.

Every call checks the Bharat Address Graph first. Only genuinely new addresses reach Claude AI — keeping cost near zero and speed near-instant.

1

Raw Address In

POST your unstructured string — landmark references, local names, partial pincodes, mixed Hindi-English. We handle all of it.

POST /parse
2

Graph + AI Resolution

DynamoDB cache checked first (~300ms). On miss, Claude Sonnet on AWS Bedrock parses the address with few-shot Indian geography examples (~2s). Result written back to graph permanently.

Bharat Address Graph
3

Structured JSON Out

Village, mandal, district, state, pincode, GPS coordinates, confidence score. Ready for your routing engine, database, or delivery platform.

village · GPS · confidence

API Reference

Two endpoints. Simple integration.

Base URL: https://v34s17v3h2.execute-api.ap-south-1.amazonaws.com/v1
POST /parse Resolve a raw Indian address
# Request curl -X POST https://v34s17v3h2.execute-api.ap-south-1.amazonaws.com/v1/parse \ -H "Content-Type: application/json" \ -H "x-api-key: YOUR_API_KEY" \ -d '{"address": "Near banyan tree, Yellareddyguda, Siddipet"}' # Response 200 OK { "input_address": "Near banyan tree, Yellareddyguda, Siddipet", "structured_address": "Yellareddyguda, Siddipet Mandal, Siddipet District, Telangana", "village": "Yellareddyguda", "mandal": "Siddipet", "district": "Siddipet", "state": "Telangana", "pincode": "502103", "lat": 18.1018, "lng": 78.8522, "confidence_score": 0.82, "latency_ms": 443, "source": "cache" }
