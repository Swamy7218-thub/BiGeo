The Technology

4-Layer Resolution Pipeline

Every address goes through four stages — knowledge base retrieval, AI disambiguation, GPS validation, and structured output — in under 2 seconds.

Step 01

Knowledge Base

Vector search across 1M+ PMGSY habitations + India Post locations indexed in AWS Bedrock. Semantic similarity in <500ms.

Step 02

LLM Disambiguation

Claude Sonnet on AWS Bedrock reads the address in context, ranks candidates, and resolves ambiguity using Indian geography reasoning.

Step 03

GPS Enrichment

HERE Maps validates coordinates. 19,559 pincode centroids serve as guaranteed fallback when live GPS is unavailable.

Step 04

Structured Output

Returns village / mandal / district / state / pincode / lat / lng / confidence score / GPS source in clean JSON via REST API.

<2 seconds end-to-end
