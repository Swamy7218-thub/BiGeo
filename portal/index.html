How It Works

Three steps. Two seconds.

A hybrid architecture combining a hand-curated village graph with Claude AI reasoning.

📍
Step 01
Raw Address In
Send any unstructured address string via a single POST request. Landmark-based, local dialect, partial pincode, or just a village name — we handle it all.
🧠
Step 02
Bharat Address Graph + Claude AI
DynamoDB cache check first (~300ms). On a miss, Claude Sonnet resolves the address against our village graph covering mandals, talukas, and district hierarchies across India.
✅
Step 03
Structured JSON Out
Receive village, mandal, district, state, pincode, GPS coordinates, a confidence score, and latency — ready to plug into any logistics, fintech, or delivery platform.

Cache hit in ~300ms. New address resolved by Claude Sonnet in ~2s.

API Reference

Simple REST API. Integrate in minutes.

One header. Two endpoints. Everything you need to resolve rural Indian addresses.

Base URL https://v34s17v3h2.execute-api.ap-south-1.amazonaws.com/v1
Authentication 
# All requests require your API key in the x-api-key header
x-api-key: your_api_key_here

# Demo key (rate-limited, for exploration only):
x-api-key: f26104e6f1c54906b16223754867268e
POST /parse

Parses any unstructured rural Indian address string into a structured JSON object with GPS coordinates.

Request — cURL 
curl -X POST \
  https://v34s17v3h2.execute-api.ap-south-1.amazonaws.com/v1/parse \
  -H "Content-Type: application/json" \
  -H "x-api-key: f26104e6f1c54906b16223754867268e" \
  -d '{"address": "Near banyan tree, Yellareddyguda, Siddipet"}'
Response — 200 OK 
{
  "village": "Yellareddyguda",
  "mandal": "Siddipet",
  "district": "Siddipet",
  "state": "Telangana",
  "pincode": "502103",
  "lat": 18.1012,
  "lng": 78.8522,
  "confidence": 0.91,
  "source": "cache",
  "latency_ms": 287
}
