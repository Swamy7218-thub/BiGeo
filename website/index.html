The Problem

India's addresses are
broken by design.

No Postal Codes

Over 60% of Indian villages have no PIN code, ward number, or unique identifier that mapping APIs can geocode.

Ambiguous Names

Thousands of villages share identical or near-identical names across states — "Rampur" appears 347 times in official records.

Fragmented Data

Census, revenue, electoral, and postal records use different village codes — creating a labyrinth that kills last-mile delivery.

₹1.4 trillion lost annually

to failed deliveries, returned parcels, and manual address correction in India — a problem BiGeo eliminates at the API layer.

How it works

Three steps.
Zero ambiguity.

BiGeo combines the Bharat Address Graph — a knowledge graph of every village relationship in India — with Claude AI's language understanding to resolve even the most ambiguous addresses.

1

You send a raw address

Any format. Any script. Hindi, Tamil, Telugu, or romanised transliterations. Even "near the banyan tree, north of the school."

POST /v1/resolve
{
  "address": "rampur village, near tehsil office, up"
}
2

BiGeo graph + AI resolves it

The Bharat Address Graph traverses 4.2M village relationships — district, taluk, block, revenue circle — while Claude AI disambiguates language and context.

4–7
AI passes
1–2
3

You get structured geocoordinates

Lat/lng with confidence score, matched village entity, state hierarchy, and a canonical address you can store and ship to.

bigeo_example.py 
import bigeo

# Initialize client
client = bigeo.Client(api_key="bge_live_...")

# Resolve a single address
result = client.resolve(
  address="Rampur village, near tehsil
           office, Lucknow, UP",
  language="en"
)

print(result.lat)      # 26.8467
print(result.lng)      # 80.9462
print(result.confidence) # 0.97
print(result.village)  # "Rampur Mathura"

# Batch resolve
results = client.resolve_batch(
  addresses=address_list,  # up to 1000
